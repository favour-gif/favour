TEMPOTRACK - A Time Management SPA

OVERVIEW

TempoTrack is a Single Page Application (SPA) designed to help users manage their tasks efficiently, track productivity, and analyze their time distribution between work and leisure. Built with HTML, CSS, and JavaScript, the application provides an intuitive interface for users to organize their schedules, monitor completed and pending tasks, and gain insights into their productivity trends.

FEATURES

Task Management: Add, edit, and delete tasks with deadlines and priority levels.
Task Completion Tracking: Mark tasks as completed and track progress over time.
Interactive Calendar: View tasks in a structured calendar layout for easy planning.
Productivity Insights: Visualize time spent on tasks versus leisure activities.
Local Storage Integration: Data is stored persistently in the browser for offline access.
User-Friendly Interface: A clean and responsive design for easy navigation.
Technology Stack

Frontend: HTML, CSS, JavaScript


Data Storage: Local Storage (JSON-based)

Version Control: Git and GitHub

INSTALLATION & USAGE

Clone the repository:
git clone https://github.com/your-username/TempoTrack.git
cd TempoTrack
Open the index.html file in your browser to run the application.
Start adding and managing tasks seamlessly!
